# 词力战士（Word Warrior）

> 一款「打怪学字词」的轻竞技教育射击游戏微信小程序。
> 字母 / 汉字当子弹，补全挖空打爆怪兽，覆盖幼儿园 → 大学的字词学习。

## 核心玩法

- 竖屏炮台射击：下方炮台发射字符子弹，上方怪兽身上是挖空的单词 / 词语 / 成语
- 挖空补全：选对字符补全即发射炮弹打爆怪兽；选错扣命
- 规则：一题一次机会、3 命制（归零整局失败）、每 10 题一关
- 评分：按正确率出 1~3 星，解锁后续关卡
- 反馈：答对 ✓ + 爆炸 + 冒星星 + 连击提示；答错怪兽逼近 + 红闪

## 技术栈

| 层 | 选型 |
|---|---|
| 前端 | 微信原生小程序（`Canvas 2D` 渲染游戏核心 + WXML 页面） |

## 功能规划

### 用户需求（5 项）
1. **形象系统**：怪兽 + 战士皮肤按「段位 / 星数」解锁，越高越华丽
2. **昵称 + 排行榜**：玩家取名，排行榜展示昵称
3. **自定义关卡**：词库导入 → 生成关卡 → 分享 → 提交审核转正式
4. **词库格式校验**：手机友好的纯文本模板 + 即时校验（详见 `docs/词库格式规范.md`）
5. **内置词库**：幼儿园 → 大学，覆盖英语 / 汉字 / 成语 / 歇后语 / 组词 / 英语填空等

### 补充功能（成熟经验）
- 错题本 + 艾宾浩斯智能复习
- 每日挑战 + 连续签到 + 补签卡
- 成就勋章系统
- 音效 / BGM（WebAudio 合成）
- 合规：隐私协议 / 用户协议（青少年模式、防沉迷经拍板不做）
- 学习报告（正确率 / 薄弱题型）

## 快速开始

### 前端（需要微信开发者工具）
1. 微信开发者工具 → 导入 `miniprogram/` 目录
2. 填 AppID，编译预览

### 后端（参考官方模板）
1. `cd server && npm install`
2. 配置 `MYSQL_ADDRESS / MYSQL_USERNAME / MYSQL_PASSWORD` 环境变量
3. 云托管控制台部署，或本地 `npm start`

> 详细开发说明见 `docs/`，SDD 工程文档见 `.codeartsdoer/specs/`（历史规格，完成状态以 `docs/当前未完成事项.md` 为准），
> 改动验证方式见 `AGENTS.md` 与 `e2e/README.md`。
