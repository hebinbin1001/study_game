# 词力战士 M4 阶段需求规格说明书

> 文档状态：M4 需求规格（v1.0）
> 适用阶段：M4（每日挑战 + 签到 + 成就 + 音效 + 学习报告 + 合规）
> 需求句式：EARS
> 关联文档：`spec.md`（M1）、`m2-avatar-rank/spec.md`（M2）、`m3-custom-level-review/spec.md`（M3）

---

## 一、概述

M4 阶段在 M1~M3 基础上，新增每日挑战、签到打卡、成就勋章、音效/BGM、学习报告、合规等功能，完善产品体验。

### 1.1 目标

1. 每日挑战：每日随机题库，限时挑战
2. 签到打卡：连续签到奖励机制
3. 成就勋章：达成条件解锁勋章
4. 音效/BGM：背景音乐 + 游戏音效
5. 学习报告：周报生成与分享
6. 合规：青少年模式 + 隐私协议 + 防沉迷

---

## 二、每日挑战

### 2.1 数据模型

#### DailyChallenge

| 字段 | 类型 | 说明 |
|------|------|------|
| challengeId | string | 唯一标识（日期） |
| date | string | 日期（YYYY-MM-DD） |
| grade | string | 学段 |
| items | array | 题目列表 |
| completed | boolean | 是否已完成 |

### 2.2 功能

1. 每日题库：按学段随机生成 10 题
2. 限时挑战：5 分钟内完成
3. 排行榜：每日挑战排行榜

---

## 三、签到打卡

### 3.1 数据模型

#### CheckinRecord

| 字段 | 类型 | 说明 |
|------|------|------|
| recordId | string | 唯一标识 |
| openid | string | 用户标识 |
| date | date | 签到日期 |
| streak | number | 连续签到天数 |

### 3.2 功能

1. 签到：每日签到一次
2. 连续签到奖励：第 3/7/14/30 天额外奖励
3. 签到日历：展示本月签到记录

---

## 四、成就勋章

### 4.1 数据模型

#### Achievement

| 字段 | 类型 | 说明 |
|------|------|------|
| achievementId | string | 唯一标识 |
| name | string | 成就名称 |
| description | string | 描述 |
| icon | string | 图标 |
| condition | object | 解锁条件 |

### 4.2 内置成就

| achievementId | name | 条件 |
|---------------|------|------|
| first_blood | 首胜 | 通关 1 次 |
| combo_master | 连击大师 | 单局连击 10 |
| star_collector | 星数收集 | 累计 50 星 |
| rank_bronze | 青铜段位 | 达到青铜 |
| rank_king | 王者段位 | 达到王者 |
| perfect_clear | 完美通关 | 单局 3 星 |

---

## 五、音效/BGM

### 5.1 功能

1. 背景音乐：战斗页 BGM
2. 音效：答对/答错/爆炸/升级
3. 音量控制：独立控制 BGM 和音效

---

## 六、学习报告

### 6.1 功能

1. 周报生成：每周学习数据汇总
2. 分享：生成海报图分享

---

## 七、合规

### 7.1 功能

1. 青少年模式：时长限制
2. 隐私协议：首次弹窗
3. 防沉迷：实名认证 + 时段限制

---

## 八、验收标准

### M4 完成标准

1. 每日挑战：每日题库 + 限时挑战可用
2. 签到打卡：签到 + 连续奖励可用
3. 成就勋章：成就系统 + 勋章展示可用
4. 音效/BGM：背景音乐 + 音效可用
5. 学习报告：周报生成 + 分享可用
6. 合规：青少年模式 + 隐私协议 + 防沉迷可用
