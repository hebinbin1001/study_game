> 文档状态：M3 需求规格（v1.0）
> 适用阶段：M3（自定义关卡 + 错题本）
> 需求句式：EARS

## 一、概述

M3 阶段在 M1/M2 基础上，新增自定义关卡系统与错题本复习系统，增强玩家创作能力与学习闭环。

### 1.1 目标

1. 自定义关卡编辑器：玩家可创建、编辑、分享自己的关卡
2. 关卡审核后台：支持提交审核、审核流转、转正式关卡
3. 错题本：记录答错题目，支持艾宾浩斯智能复习
4. 艾宾浩斯复习算法：按 1/2/4/7/15 天间隔推送待复习题目

### 1.2 范围边界

- 形象/段位/排行榜（M2 已完成）
- 每日挑战/签到/成就/音效/合规（M4）

## 二、自定义关卡系统

### 2.1 数据模型

#### 自定义关卡（CustomLevel）

| 字段 | 类型 | 说明 |
|------|------|------|
| levelId | string | 唯一标识 |
| title | string | 关卡标题 |
| description | string | 关卡描述 |
| authorOpenid | string | 作者 openid |
| grade | string | 学段 |
| items | array | 题目列表（词条 ID 或内联词条） |
| totalQ | number | 总题数 |
| status | string | `draft`（草稿）/ `pending`（待审核）/ `approved`（通过）/ `rejected`（拒绝） |
| shareCode | string | 分享码（6 位） |
| createdAt | timestamp | 创建时间 |
| updatedAt | timestamp | 更新时间 |

#### 关卡审核记录（LevelReview）

| 字段 | 类型 | 说明 |
|------|------|------|
| reviewId | string | 审核记录 ID |
| levelId | string | 关卡 ID |
| reviewerOpenid | string | 审核员 openid |
| status | string | `approved` / `rejected` |
| comment | string | 审核意见 |
| createdAt | timestamp | 审核时间 |

### 2.2 自定义关卡编辑器

#### 功能

1. 创建关卡：输入标题、描述、选择学段
2. 添加题目：从词库选择或手动输入
3. 调整题目顺序：拖拽排序
4. 预览关卡：模拟出题
5. 保存草稿 / 提交审核

#### 页面结构

- 关卡信息区：标题、描述、学段选择
- 题目列表区：已添加题目 + 添加按钮
- 操作区：保存草稿、提交审核、预览

### 2.3 关卡分享

#### 分享方式

1. 分享码：6 位字母数字，好友输入分享码导入关卡
2. 小程序卡片：生成分享卡片，点击直接进入关卡

#### 分享接口

| 接口 | 方法 | 语义 |
|------|------|------|
| POST /api/level/share | 生成分享码 |
| GET /api/level/import?code=xxx | 导入关卡 |

### 2.4 审核后台（管理端）

#### 功能

1. 待审核列表：按时间倒序
2. 审核详情：查看关卡内容、题目列表
3. 审核通过/拒绝：更新状态 + 通知作者

#### 页面结构

- 待审核列表页
- 审核详情页
- 审核记录页

## 三、错题本系统

### 3.1 数据模型

#### 错题记录（WrongRecord）

| 字段 | 类型 | 说明 |
|------|------|------|
| recordId | string | 唯一标识 |
| openid | string | 用户标识 |
| questionId | string | 题目标识（词条 q + type） |
| question | object | 题目快照（q/a/hint/type） |
| wrongCount | number | 错误次数 |
| lastWrongAt | timestamp | 最近错误时间 |
| nextReviewAt | timestamp | 下次复习时间 |
| reviewCount | number | 已复习次数 |
| lastReviewAt | timestamp | 最近复习时间 |
| mastery | number | 熟练度（0~100） |

### 3.2 艾宾浩斯复习算法

#### 复习间隔

| 复习次数 | 间隔天数 |
|----------|----------|
| 1 | 1 天 |
| 2 | 2 天 |
| 3 | 4 天 |
| 4 | 7 天 |
| 5 | 15 天 |
| 6+ | 30 天（稳定） |

#### 算法逻辑

```
1. 首次答错：nextReviewAt = now + 1 天
2. 复习答对：mastery += 20，按当前 reviewCount 取间隔
3. 复习答错：mastery = max(0, mastery - 10)，重置复习次数
4. mastery >= 100：标记为已掌握，不再推送
```

### 3.3 错题本页面

#### 功能

1. 错题列表：按下次复习时间排序
2. 复习模式：逐题作答，反馈正误
3. 错题统计：总错题数、待复习数、已掌握数

#### 页面结构

- 错题列表页：分组展示（待复习/已掌握）
- 复习页：逐题作答 + 反馈
- 错题详情页：题目 + 错误次数 + 复习记录

### 3.4 接口需求

| 接口 | 方法 | 语义 |
|------|------|------|
| GET /api/wrong/list | 获取错题列表 |
| POST /api/wrong/add | 添加错题记录 |
| POST /api/wrong/review | 复习作答 |
| GET /api/wrong/stats | 错题统计 |

## 四、验收标准

### M3 完成标准

1. **自定义关卡编辑器**：创建/编辑/保存草稿/提交审核可用
2. **关卡分享**：分享码生成 + 导入可用
3. **审核后台**：待审核列表 + 审核详情 + 通过/拒绝可用
4. **错题本**：错题记录 + 艾宾浩斯复习 + 复习页可用

### 测试用例

- 自定义关卡：创建 → 提交审核 → 审核通过 → 可玩
- 分享码：生成 → 好友导入 → 关卡一致
- 错题本：答错 → 自动记录 → 按间隔推送复习
- 艾宾浩斯：复习答对 → 间隔递增；答错 → 重置
