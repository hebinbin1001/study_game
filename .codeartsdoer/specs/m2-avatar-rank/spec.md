# 词力战士 M2 阶段需求规格说明书

> 文档状态：M2 需求规格（v1.0）
> 适用阶段：M2（形象/段位/排行榜）
> 需求句式：EARS
> 关联文档：`spec.md`（M1 核心玩法）、`design.md`（M1 设计）

---

## 一、概述

M2 阶段在 M1 核心玩法基础上，新增形象/皮肤/段位系统与排行榜完整版，增强玩家长期动力与社交竞争感。

### 1.1 目标

1. 形象系统：怪兽 + 战士皮肤按「段位/星数」解锁，关卡得分越高形象越华丽
2. 段位系统：青铜→王者 8 段位晋升，按累计胜场/星级晋升
3. 排行榜：好友排行榜（微信开放域）+ 世界排行榜（全服 Top 100）
4. 昵称展示：排行榜头像 + 昵称渲染

### 1.2 范围边界（Out of Scope）

- 自定义关卡（M3）
- 错题本（M3）
- 每日挑战/签到/成就/音效/合规（M4）

## 二、形象系统

### 2.1 数据模型

#### 形象（Avatar）

| 字段 | 类型 | 说明 |
|------|------|------|
| avatarId | string | 唯一标识，如 `warrior_01`、`monster_01` |
| name | string | 形象名称 |
| type | string | `warrior`（战士）/ `monster`（怪兽） |
| rarity | string | `common`（普通）/ `rare`（稀有）/ `epic`（史诗）/ `legend`（传说） |
| icon | string | 图标路径 |
| unlockCondition | object | 解锁条件 |

#### 解锁条件（UnlockCondition）

| 字段 | 类型 | 说明 |
|------|------|------|
| type | string | `stars`（总星数）/ `rank`（段位）/ `level`（关卡）/ `free`（默认解锁） |
| value | number | 阈值（如 stars≥50、rank≥3） |

### 2.2 段位系统

#### 段位定义

| 段位 | 等级 | 晋升条件（累计胜场） | 标识 |
|------|------|---------------------|------|
| 青铜 | 1 | 0 | 🥉 |
| 白银 | 2 | 10 | 🥈 |
| 黄金 | 3 | 30 | 🥇 |
| 铂金 | 4 | 60 | 💎 |
| 钻石 | 5 | 100 | 💠 |
| 星耀 | 6 | 150 | ✨ |
| 王者 | 7 | 220 | 👑 |
| 荣耀王者 | 8 | 300 | 🏆 |

#### 段位数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| rankId | number | 段位 ID（1~8） |
| rankName | string | 段位名称 |
| icon | string | 段位图标 |
| minWins | number | 晋升所需累计胜场 |

### 2.3 形象列表（M2 内置）

#### 战士皮肤（Warrior）

| avatarId | name | rarity | unlockCondition |
|----------|------|--------|-----------------|
| warrior_01 | 初学者战士 | common | free |
| warrior_02 | 学徒战士 | rare | stars≥30 |
| warrior_03 | 精英战士 | epic | rank≥3（黄金） |
| warrior_04 | 传说战士 | legend | rank≥7（王者） |

#### 怪兽皮肤（Monster）

| avatarId | name | rarity | unlockCondition |
|----------|------|--------|-----------------|
| monster_01 | 小怪兽 | common | free |
| monster_02 | 火焰怪兽 | rare | stars≥50 |
| monster_03 | 冰霜怪兽 | epic | rank≥4（铂金） |
| monster_04 | 雷霆巨兽 | legend | rank≥6（星耀） |

### 2.4 接口需求

| 接口 | 方法 | 语义 | 关键入参 | 关键出参 |
|------|------|------|----------|----------|
| GET /api/avatar/list | GET | 获取可用形象列表 | openid | 形象列表 + 已解锁状态 |
| POST /api/avatar/unlock | POST | 解锁形象 | openid, avatarId | 解锁结果 |
| GET /api/rank/info | GET | 获取段位信息 | openid | 当前段位 + 胜场 |
| GET /api/rank/progress | GET | 获取段位晋升进度 | openid | 当前胜场 + 距下一段位差 |

## 三、排行榜系统

### 3.1 好友排行榜（微信开放域）

#### 数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| rankId | string | 排行榜记录 ID |
| openid | string | 用户标识 |
| nickname | string | 昵称 |
| avatarUrl | string | 头像 URL |
| score | number | 总分 |
| stars | number | 总星数 |
| rankLevel | number | 段位等级 |
| updatedAt | timestamp | 更新时间 |

#### 接口需求

| 接口 | 方法 | 语义 | 关键入参 | 关键出参 |
|------|------|------|----------|----------|
| GET /api/rank/friends | GET | 好友排行榜 | openid | Top N 好友列表 |
| GET /api/rank/world | GET | 世界排行榜 | page, pageSize | 分页 Top 100 |
| GET /api/rank/me | GET | 我的排名 | openid | 我的排名 + 数据 |

### 3.2 排行榜展示

#### 好友排行榜页

- 展示好友 Top 20（头像 + 昵称 + 段位图标 + 总分 + 星数）
- 高亮当前用户位置
- 支持刷新

#### 世界排行榜页

- 展示全服 Top 100
- 分页加载（每页 20）
- 前三名特殊样式（金银铜牌）

## 四、昵称展示

### 4.1 头像 + 昵称组件

- 头像圆形裁剪

- 段位小图标角标

### 4.2 使用场景

- 排行榜列表项
- 结算页玩家信息
- 首页用户卡片

## 五、验收标准

### M2 完成标准

1. **形象系统**：形象数据模型 + 解锁逻辑 + 形象选择页可用
2. **段位系统**：8 段位定义 + 晋升逻辑 + 段位展示可用
3. **排行榜**：好友/世界排行榜 + 我的排名查询可用
4. **昵称展示**：头像 + 昵称 + 段位图标渲染正常

### 测试用例

- 段位晋升：累计胜场达到阈值后段位正确晋升
- 形象解锁：达到条件后形象正确解锁
- 排行榜：数据上报后正确展示排名
- 幂等性：重复上报成绩不重复计分
