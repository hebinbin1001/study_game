# M7 闯关玩法形态化 + 关卡路径地图（spec & 任务）

> 拍板（2026-09-08）：形态**玩家自选**（进关前在 game 页选 经典/Boss/竞速）；竞速**每题限时 8s**；关卡页在**当前学段+分类体系上做多邻国式蛇形路径地图**。

## 一、目标
1. 对局形态化：经典（现状）、Boss 爽感（Demo2）、极速竞速（Demo3）三种玩家可选；
2. 关卡选择页从网格卡改为多邻国式蛇形路径地图（保留学段/分类/解锁/存档体系）。

## 二、不可破坏的公共内核（三形态与地图重构必须保持）
- 一关 10 题、一题一次机会、3 ❤、答对 +1 题 +10 分、答错扣 ❤、超时(仅竞速)=本题判错并扣 ❤；
- **实际分 = 答对数 × 10**（服务端推导口径、星级/成绩/排行/报告/成就/错题本零改动）；
- 登录/游客限制、默认解锁前 3 关+逐关解锁、题型分类(grade@type@level 存档)、皮肤/段位、callContainer 请求、音效/朗读/声音开关、新手引导、首字母大写展示——全部保持。
- Boss 血条/连击倍率/时间奖励等一律为**表现层**，不进实际 score。

## 三、Phase A：对局形态（玩家自选）
- 文件主改：`pages/game/game.js/.wxml/.wxss`、`game/engine.js`、`game/renderer.js`、必要时 `game/config.js` 增形态常量。
- game 页进入对局前（或首次 onLoad 顶部）展示形态选择：经典对战 / Boss 狂潮 / 极速竞技（默认记住上次选择，可存 ww_mode）。选择后带 mode 参数进入对局（建议独立小屏或弹层）。
- engine 增加 `G.mode`（'classic'|'boss'|'rush'）注入；判定/计分/状态机共享，差异：
  - **classic**：维持现状渲染。
  - **boss**：题目仍在怪兽/卡片区（可把怪兽描画替换为 Boss 化 emoji+血条 HUD）；答对=命中特效（顿帧+伤害飘字×连击视觉+粒子）与血条扣格（血条格=总题数进度视觉，非真实数值）；Boss 阶段≤25% 变红/暴怒氛围；答错=Boss 挥击/逼近感+❤红闪；通关=击破结算动画。**不引入第二套判定**。
  - **rush**：每题 8s 倒计时条（超时=本题判错并走答错流程）；连击徽标×倍率与"+XX ×N ⏱"飘字仅展示；答对极快切题（缩短 DYING 到可配）；答错惩罚锁 0.8s 禁点。
- 结算页显示本局形态（可选小标签）；形态不写入成绩上报字段。
- 规则一致性：无论形态，答错/超时均扣❤，❤尽→失败结算。

## 四、Phase B：关卡蛇形路径地图（level 页重构）
- 保留：学段 tab、题型分类 chips（含题量、不足提示）、游客横幅、默认解锁 3+逐关、needLogin、分类徽标、进度卡、进关参数 grade/type/level。
- 视觉：当前分类的 10 关改为**蛇形路径**（推荐 3 列、纵向可滚动；单关节点显示 关卡号或主题名/分类徽标/星）。节点状态：已通关=金色✔+星（可重玩）、当前未通第一个=高亮呼吸“继续”、未解锁=灰锁+条件小字；连线随已解锁点亮。CSS/布局在 level.wxml/.wxss/.js 完成；不改后端与存储结构。

## 五、任务
- A1 engine 注入 mode 与 boss/rush 表现钩子（不动判定）；A2 game 页形态自选 UI+记忆；A3 boss 表现（血条/命中/Boss化/击破）；A4 rush 表现（每题计时/超时判错/惩罚锁/连击视觉）；A5 game.wxss/wxml 形态 HUD；A6 结算标注形态。
- B1 level 布局改蛇形路径 + 连线点亮；B2 节点交互与既有解锁/点击逻辑合并；B3 样式打磨（01 demo 观感：金✔/呼吸/条件小字）。
- 验证：每文件 node --check；npm test 全绿；node e2e/check-wxss.js；人工在开发者工具跑 classic/boss/rush 各一关与 level 地图。
