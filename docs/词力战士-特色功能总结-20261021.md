# 词力战士 · 特色功能总结

## 一句话定位

把字词、成语和数学题做成短局闯关小游戏：答对立即有反馈，答错自动进入复习，用段位和形象系统推动持续练习。

## 核心特色

| 特色 | 具体能力 | 用户价值 |
| --- | --- | --- |
| 打怪式学习 | 补全缺字/缺字母，选对后发射攻击，选错立即显示答案 | 把延迟的“背完再考”变成即时反馈 |
| 多玩法 | 当前 19 款已开放玩法：7 款字词线 + 12 款数字智力 | 同一批知识可以换不同方式练，不容易腻 |
| 全学段内容 | 14 个学段，2423 条内置内容 | 从幼儿园到大学都能找到对应难度 |
| 教材与题型 | IPA 音标；小学支持 PEP / 外研版；8 类字词题型 | 更贴近课本与真实练习场景 |
| 主线与 BOSS | 每学段 30 关，第 30 关为 15 题、7 命 BOSS 关 | 有明确的阶段目标和仪式感 |
| 错题复习 | 自动收集错题，按 1/2/4/7/15/30 天安排复习 | 错题变成下一次练习的路线，而不是一次性的挫败 |
| 掌握判定 | 连续答对 6 次才进入“已掌握” | 减少“答对一次就以为会了”的错觉 |
| 学习报告 | 答题量、正确率、薄弱题型、玩法分布 | 家长不用全程盯着也能看见真实进度 |
| 成长体系 | 9 大段位、81 小级、48 套形象、51 个成就 | 奖励长期练习，而不是随便点击就送金币 |
| 每日目标 | 每日挑战、双月赛季、好友 PK | 给已经形成习惯的孩子提供短期目标 |
| 自定义题库 | 新建题库、挂到年级、编辑词条并直接参与出题 | 能把老师当天听写或自家薄弱词放进去 |
| 低门槛体验 | 微信打开即玩；游客可先试前 3 关 | 先体验手感，再决定是否注册 |

## 产品边界

- 每局有明确结束点，不做无限时长。
- 皮肤和段位不靠付费加速，不做付费变强。
- 排行榜和好友 PK 有社交激励，但不做私信与好友聊天。
- 不替代老师和家长，定位是每天 10 分钟的高频练习入口。

## 最值得对外讲的差异点

不是“游戏很多”，而是：

1. **学习反馈足够快**：答对、答错、补全、战斗结果在同一次点击里完成。
2. **玩法和学习进度是一体的**：换玩法不用换一套记录。
3. **错题真的会回来**：自动安排复习，连续答对才判定掌握。
4. **成长奖励来自长期练习**：星星、段位、形象、成就互相连接。

> 对外文案避免承诺“保证提分”“孩子一定上瘾”等不可验证结果；可以讲即时反馈、短局设计、复习机制和内容覆盖。
