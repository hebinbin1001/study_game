### A. 需要你拍板（1 条）

**A1. 导航栏标题的白字对比度不够。** 这个我建议你看一眼再定。

| 现状 | 白字对比度 | 标准 |
|---|---|---|
| `app.json` window 的 `#4a9fe8`（全站默认） | 2.83:1 | 4.5:1 |
| 玩法页最低：`clock` 的 `#f0a020` | 2.15:1 | |

| `pattern #7c6cf0` / `hanoi #d94f85` | 3.99 / 3.88 | |

导航栏标题 17px semibold，按 WCAG 不算「大字」，所以标准是 4.5:1。三条路：

- **方案 A（推荐）**：全站导航栏统一加深到 `#2d74b8`（4.88:1）。页面背景首色要同步改，
  接缝由 `check-nav-seam.js` 兜住。代价：所有页面顶部深一档。
- **方案 B**：`navigationBarTextStyle` 改 `black`。浅蓝底黑字很清楚，
  但和「白字压天空」的整体感不一致，且深色玩法页（memory-grid `#2b3a67`）得单独切回白字。
- **方案 C**：不修，接受行业惯例。多数小程序蓝底白字都在 3:1 左右。

不做决定就维持现状，不影响其它事。

### C. 需要真机（3 条）

### C+. 新发现、待排期（4 条，都不影响当前使用）

**C4. 8 处返回/关闭控件的热区仍然不足 —— 它们绕过了批 7 的护栏。**
批 7 加的规则只认「显式写了 width/height」的规则，这批是靠 padding 或行高撑的，

「width/height/padding 三者取大，仍 < 88rpx 就报」。
