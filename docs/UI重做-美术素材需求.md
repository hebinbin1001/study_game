## 三、风格基准（必须与现有素材同一套画风）

- 可爱卡通、有体积感的圆润造型（明暗分明、有高光和落地感），**不要扁平描边风、不要写实**。
- 参考文件（体积感、描边粗细、五官比例照它对齐）：
  - `miniprogram/assets/skins/monster_01.png`（画风基准）
  - `art/skins/boss_crimson_ogre.png`、`art/skins/boss_jade_dragon.png` 等现有 6 款 Boss
- 主色必须占主体大面积，高光只占小面积，不要整体发白。

## 四、硬性约束（老规矩，踩过坑）

- **真透明底 PNG（alpha 通道）**，不要棋盘格模拟底、不要白底、不要纯色底；
- 图上**不要任何文字 / 数字 / 字母 / 水印 / logo**；
- **不留任何外框、卡片边框、底板、圆形底托、渐变背景**；
- **不要画地面阴影**（端上由代码加投影，图里带了会出现双影）；
- 主体居中，四周留约 8% 安全边距，在浅色背景上清晰可辨；
- 结算页的「被击败灰态」不用画——端上用 CSS 滤镜（grayscale）现场处理，省美术量。

## 五、交付规格

- 每张 **512×512** 独立 PNG；如用 AI 出图，可先拼 4 列 × 2 行集合图（整图 2048×1024）再切分；
- 保存目录：`E:\Code\小程序\study_game\assets-src\skins\`（**不要动 `miniprogram/` 目录**）；
- 文件名严格用上表 8 个名字（全小写、下划线）；
- 回报只需：每个文件的路径 + 尺寸 + 是否真透明底。

## 六、交付后由开发侧完成（不用设计师管）

4. 首页 Boss 预告卡 / 对局页 / 结算页按映射取图。
