## 一、玩法矩阵（去重后的最终清单）

### 先定一个模型：玩法分两类，关卡语义不同

| 类别 | 关卡从哪来 | 关卡数 | 举例 |
|---|---|---|---|
| **题库类** | 内容由**内置词库**动态生成（按 学段 + 题型 过滤出题） | 每学段固定 10 关，每关 10 题；换学段就是全新的一轮 | 字母射击、字母拼词、成语拼字、词义配对、连连看、贪吃蛇 |
| **固定关卡类** | 关卡是**预设/程序生成**的谜题，与词库无关 | 各自一套（数独 20、2048 7、其它 8~20） | 数独、2048、算 24 点、算式天平、口算冲刺、记忆矩阵、一笔画 |

> 这正是你说的"数字游戏是固定关卡，其他从题库生成"——把它固化成两种关卡类型，

## 二、闯关形态怎么处理（这条要你拍板）

现状：经典 / Boss 狂潮 / 极速竞技 三种形态**判定、计分、节奏骨架完全一致**，
Boss 的血条本质就是"答对进度条"——它们只是换皮。你的判断是对的。

两个方向：

| 方向 | 做法 | 代价 |
|---|---|---|
| **A. 直接删除（推荐）** | 三种形态整个去掉，只留现在这套标准规则；玩法 tab 保持干净 | 小（删代码，无新逻辑） |
| B. 升级为真玩法 | 把 Boss 狂潮、极速竞技 做成**独立玩法卡**，并真的给它们不同规则（Boss 有弱点部位、极速有时间奖励）；经典保留为"字母射击"本体 | 中（需要设计并实现差异化规则，即原 R8） |

> 你原话是"改到玩法 tab 里 + 重复了可以删除"。若选 A，就是**删掉**；
> 若选 B，就是**移进玩法 tab 并做成真玩法**。我建议先 A —— 先把体系理顺，
> 差异化玩法等新玩法都并进来之后再谈。

## 三、关卡选择的三个候选（替代蛇形曲线）

三个候选都满足：**不画曲线**、题库类与固定类都能用、宽度自适应、星级与锁定状态清楚。

### 候选 A：横向卡片轨道
一关一张卡，横向滑动，当前关居中并高亮。

```
← 字母射击                        ★ 6/30
幼儿园 · 综合 · 已通关 3/10
┌────────┐ ┌────────┐ ┌────────┐
│   1    │ │   2    │ │   3    │
│  ★★★   │ │  ★★☆   │ │ 继续 ▶ │
│  单词   │ │  词语   │ │  成语   │
└────────┘ └────────┘ └────────┘
```
- 优点：视觉干净、卡片能放足够信息（关卡号/星级/题型）、滑动天然适配宽度
- 缺点：10 关要滑 3~4 屏，看不到全局

### 候选 B：竖排关卡列表（推荐）
一行一关，信息最全，纵向滚动。

```
← 字母射击                        ★ 6/30
幼儿园 · 综合 · 共 10 关 · 已通 3
┌──────────────────────────────────┐
│ ①  单词 · 第 1 关     ★★★  重玩 › │
│ ②  词语 · 第 2 关     ★★☆  重玩 › │
│ ③  成语 · 第 3 关     ▶ 继续挑战   │
│ 🔒 第 4 关      通关第 3 关后解锁   │
│ 🔒 第 5 关      ...               │
└──────────────────────────────────┘
```
- 优点：**信息密度最高**（能直接看到每关考什么题型）、关卡多少都能用、天然自适应（列表滚动，不需要算高度）
- 缺点：偏"列表"，不如卡片活泼

### 候选 C：章节网格
按章节分组，每组 6 关，3 列网格。

```
第 1 章 · 入门                 ★ 8/18
┌────┐ ┌────┐ ┌────┐
│ 1  │ │ 2  │ │ 3  │
│★★★ │ │★★☆ │ │ ▶  │
└────┘ └────┘ └────┘
┌────┐ ┌────┐ ┌────┐
│ 4  │ │ 5  │ │ 6  │
│ 🔒 │ │ 🔒 │ │ 🔒 │
└────┘ └────┘ └────┘
第 2 章 · 进阶 🔒（通关第 1 章解锁）
```
- 优点：一屏能看 6~9 关、有"章节推进感"、网格天生工整
- 缺点：格子小，放不下题型信息

### 固定关卡类长什么样（以数独为例）

```
← 数独                        已通关 7/20
4×4 → 6×6 → 9×9 · 提示数递减
┌──────────────────────────────────┐
│ ①  4×4 · 入门      ★★★   重玩 ›  │
│ ②  4×4 · 标准      ★★★   重玩 ›  │
│ ③  4×4 · 挑战      ★★☆   重玩 ›  │
│ ④  6×6 · 入门      ★☆☆   重玩 ›  │
│ 🔒 ⑧  6×6 · 进阶   通关第 7 关解锁 │
└──────────────────────────────────┘
```
固定类的"一行"结构同样适用（候选 B），只是第二列从"题型"换成"关卡目标/规格"。
