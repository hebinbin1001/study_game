# 玩法线改造（P3 一期）—— 需求与落地方案

> 触发：用户 2026-09-13 反馈「闯关学习只有从字母射击才可以进去，其他题库的玩法都是单独的，
> 不太合理」。拍板：「都按你建议的来」+「按玩法页顶部二级分段，另外几个 tab 还缺图标，一并改下」。
> 本文是需求与落地口径的唯一说明；进度与待办见 `docs/项目进展与待办.md`。

## 一、问题（改造前）

| 入口 | 改造前行为 | 问题 |
| --- | --- | --- |
| 首页「继续挑战」 | 进 30 关主线（6 玩法轮换） | 只有一条线，想玩连连看得先按顺序打通 |
| 玩法 tab 6 款题库玩法 | 除字母射击外，点进去都是**自由练** | 没有关卡、不写进度、星级体系不参与 |
| 关卡页「分类」 | 单词/填空/词语/成语/歇后语 → 都是**字母射击页** | 换题库不换玩法，语义拧巴 |

一句话：**关卡体系只长在字母射击这一条线上。**

## 二、方案选型

| 方案 | 做法 | 结论 |
| --- | --- | --- |
| A 玩法即关卡线 | 6 款题库玩法各一条 30 关独立线；主线降级为「综合闯关」 | ✅ 采用（一期） |
| B 单主线 + 玩法筛选 | 保持一条主线，加「按玩法看」筛选、支持跳关 | ❌ 想玩连连看仍要先过前几关，诉求只解决一半 |
| C 玩法 + 段位 | 不设关卡，用段位表示玩法进度 | ❌ 与「闯关感」不是一路，且和现有段位体系冲突 |

页面结构上另有取舍：**数字智力类不做第 5 个底部 tab，先做玩法页内的二级分段** —— 底部已占 4 个位，
再加会稀释「学习」；分段零素材成本、随时可升级（升级只需补两枚 tab 图标）。

## 三、交互设计（一期）

**玩法 tab**
- 顶部二级分段：`🎯 闯关线`（6 款题库玩法，各 30 关）/ `🧠 数字智力`（9 款独立小游戏）。
- 分类行 chips 补图标（🎮 全部 / 🔫 射击 / 🃏 配对 / 🔗 连线 / 🐍 反应 / 🧮 数学 / 🧩 智力 / 🔤 拼写），
  分类 key 沿用历史值，不动存档与统计口径。
- 闯关线的卡片显示该线进度徽标「已通关 x/30」，按钮文案「去闯关」；数字智力类为「开始」。

**关卡页**
- chips 顺序：`🎯 挑战主线`（30 关轮换 + Boss）→ 6 条玩法线（带 emoji 与「已通关 x/30」）→ 题型练习
  （单词/填空/词语/成语/歇后语，10 关，字母射击 + 题型过滤）。
- 支持 `?mode=<玩法>` 直达某条线（玩法 tab 卡片就是这么跳的）。
- 玩法线关卡行：玩法名不重复展示（页面已表明是哪条线），副标题显示难度摘要（如「8 对 · 16 张牌」）。

## 四、数据与存档口径

三套命名空间并存、互不覆盖（这是本次最容易踩的坑）：

| 线 | 存档键 | 说明 |
| --- | --- | --- |
| 挑战主线 | `<学段>@challenge@<关卡>` | 原样不动 |
| 玩法线 | `<学段>@mode_<玩法>@<关卡>` | **必须带 `mode_` 前缀** |
| 题型练习 | `<学段>@<题型分组>@<关卡>` | 原样不动（word / fill / wordCn / idiom / xhy） |

> ⚠️ 为什么玩法线一定要 `mode_` 前缀：成语拼字的玩法 key 就叫 `idiom`，而「成语」也是一个题型分组 key，
> 裸 key 会让两个体系互相覆盖存档。单测 `challenge-lines.test.js` 钉住了这条。

玩法线种子 = `hash('line:' + 学段 + ':' + 玩法 + ':' + 关卡)`：同一关每次进入是同一套题（可重玩刷星、
可分享复盘），且与主线同一 (学段, 关卡) 的种子不同。

## 五、难度递增设计

约束来自「星级三档都要拿得到」（R1 老坑：题量与命数不匹配会造出某档星永远拿不到的死区）：

- **字母射击**：题量 10→15、命数 5→6（每档见 `LINE_SHOOT_RAMP`）。只加题量不加命数会把最低通关
  正确率顶到 70% 以上，1 星（60~70%）就没了。
- **字母拼词 / 成语拼字**：题量逐档递增，但**自动跳过会造出 1 星死区的题量**（5 命时 t=7 的可达正确率
  是 42.9/57.1/71.4/85.7/100%，60~70% 取不到；t≥14 时最低也有 71.4%）。见 `lineSafeCount`。
- **单词贪吃蛇**：目标词 5→10。星级按剩余命折算，不受词量影响。
- **词义消消乐 / 词语连连看**：**一期不递增**。牌面 4×4（8 对）在手机上已定型，加牌破版式；
  星级按「剩余命 3/2/1」折算，减命会让 3 星直接消失。二期用「多轮 / 限时」做难度。
- 配对类（消消乐/连连看）与题型练习的 10 关口径**保持原样**，避免老存档语义漂移。

## 八、二期与遗留

1. 配对类难度（多轮 / 限时）。
2. 玩法线内页标题带玩法名（`contextOf().label` 已备好，页面替换即可）。
3. 数字智力类是否升成第 5 个底部 tab（视内容厚度）。
4. 玩法线星级与排行榜口径：**一期沿用现有口径** —— 玩法线通关照常上报成绩并同步星星
   （`play-report.js` → `/api/score` + `/api/rank/sync`，与主线同一条链路），因此累计星星会随玩法线增长；
   当前排行榜不区分「哪条线」。若希望排行榜只统计主线，二期在服务端按 `game_type` / 线过滤即可（前端不用改）。
5. 华容道版权确认、错题本真机端到端、云托管 Git 自动部署链路（平台侧）—— 见待办文档。
