# 词库格式规范（v1）

> 目标：让用户**在手机上就能轻松**编辑、导入词库。主推纯文本模板，一行一条。

## 一、核心原则

1. **手机友好**：记事本 / 备忘录即可编辑，无需专门软件
2. **一行一条**：每条词目占一行，字段用 `|` 分隔
3. **可校验**：导入时逐行校验，报错定位到行号 + 原因
4. **可选干扰项**：干扰项可省，缺省由系统按题型算法自动生成

## 二、通用行格式

```
类型码|题目|答案|提示/释义|干扰项(可选)
```

- 字段之间用 ASCII `|` 分隔（避免中文输入法全角 `｜`，校验时自动纠正）
- 挖空位置在「题目」中用 `*` 标记；不标 `*` 时由系统默认挖（单词优先挖元音，成语挖中间字）
- `提示/释义`：英语题填中文释义，汉字/成语题填释义或拼音
- `干扰项`：逗号 `,` 分隔，缺省留空

## 三、类型码一览

| 类型码 | 题型 | 题目示例 | 答案 | 说明 |
|---|---|---|---|---|
| `w1` | 单词挖 1 格 | `cat` | `a` | 已挖/默认挖 1 个字母 |
| `w2` | 单词挖多格 | `*l*ph*nt` | `elephant` | `*` 标记每个挖空字母 |
| `c1` | 汉字/成语挖 1 字 | `守*待兔` | `株` | 挖 1 个汉字 |
| `c2` | 词语/成语挖多字 | `*心*意` | `一心` | 挖多个汉字 |
| `xhy` | 歇后语 | `芝麻开花` | `节节高` | 前半句→后半句 |
| `zc` | 组词 | `大` | `小` | 给字选可组词的字 |
| `fill` | 英语句子填空 | `I have * apple.` | `an` | 句子挖空 |
| `trans` | 中英互译 | `苹果` | `apple` | 看中文选英文 |

## 四、各题型完整示例

```
# 单词挖 1 格（默认挖元音，也可显式标 *）
w1|cat|a|猫|e,o,i
w1|d*g|o|狗|

# 单词挖多格
w2|*l*ph*nt|elephant|大象|
w2|be*u*i*ul|beautiful|美丽的|

# 汉字 / 成语挖 1 字
c1|守*待兔|株|比喻不主动努力|珠,柱,林
c1|*箭双雕|一|比喻一举两得|二,三,四

# 词语 / 成语挖多字
c2|*心*意|一心|形容专心|三心,二意,全心全意

# 歇后语（后半句填空）
xhy|芝麻开花|节节高|越来越棒|
xhy|十五个吊桶打水|七上八下|形容心情不安|

# 组词
zc|大|小|big|太,天,犬

# 英语句子填空
fill|I have * apple.|an|我有一个苹果|a,the,one
fill|She * to school.|goes|她去上学|go,going,went

# 中英互译（看中文选英文）
trans|苹果|apple|英译中|pear,banana,orange
```

## 五、校验规则（导入时执行）

| 校验项 | 规则 | 报错提示 |
|---|---|---|
| 类型码 | 必须属于 8 种之一 | `第 N 行：类型码「xx」不认识` |
| 字段数 | ≥ 3（缺「干扰项」可接受） | `第 N 行：字段不足，缺「提示/释义」` |
| 挖空标记 | `*` 数量与答案长度一致（w2/c2） | `第 N 行：挖空数(*)与答案不符` |
| 答案一致性 | 答案字符 ∈ 题目字符集 | `第 N 行：答案「x」不在题目中` |
| 干扰项 | 干扰项不含正确答案 | `第 N 行：干扰项重复正确答案` |
| 重复词条 | 相同「题目」去重提醒 | `第 N 行：与第 M 行题目重复` |
| 敏感词 | 命中过滤词库 | `第 N 行：包含敏感内容` |

## 六、导入入口（规划）

- 微信聊天文件 / 文件传输助手
- 剪贴板粘贴（复制文本一键导入）
- 内置模板下载（提供空模板 + 示例）
- 二维码导入（生成链接）

## 七、内置词库分级（规划）

| 学段 | 覆盖 |
|---|---|
| 幼儿园 | 字母认知、拼音、简单汉字 |
| 小学 1-2 | CVC 单词、基础汉字、组词 |
| 小学 3-4 | 常用单词、词语、简单成语 |
| 小学 5-6 | 单词、成语、歇后语 |
| 初中 | 中考词汇、文言实词、易混词 |
| 高中 | 高考词汇、语法填空、成语 |
| 大学 | 四六级 / 考研词汇、完形填空 |
