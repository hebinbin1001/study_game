# 题库（词条编辑）· 生产库建表与部署说明

> 2026-09-18 新增功能：题库页可查看/新增/改写/停用各学段词条，且这些词条就是**闯关线的题源**。
> 用户改动存在新表 `word_entries`（云端为真源，本地另有缓存保证离线可出题）。

## 一、必须在生产库执行这条 SQL（否则编辑不能跨设备保存）

```sql
CREATE TABLE IF NOT EXISTS `word_entries` (
  `entryId`    CHAR(36)     NOT NULL COMMENT '覆盖记录 ID',
  `openid`     VARCHAR(64)  NOT NULL COMMENT '所属用户 openid',
  `itemKey`    VARCHAR(191) NOT NULL COMMENT '词条指纹 grade|type|q',
  `action`     ENUM('create','patch','disable') NOT NULL COMMENT '新增/改写内置/停用内置',
  `grade`      VARCHAR(32)  NOT NULL COMMENT '学段 key',
  `type`       VARCHAR(16)  NULL COMMENT '题型码 w1/w2/c1/c2/xhy/zc/fill/trans',
  `q`          VARCHAR(255) NULL COMMENT '题目（w2/c2 为含 * 的模板）',
  `a`          VARCHAR(255) NULL COMMENT '答案',
  `hint`       VARCHAR(255) NULL COMMENT '提示 / 释义',
  `ex`         VARCHAR(512) NULL COMMENT '例句（可选）',
  `d`          VARCHAR(255) NULL COMMENT '干扰项（逗号分隔，可选）',
  `createdAt`  DATETIME     NOT NULL,
  `updatedAt`  DATETIME     NOT NULL,
  PRIMARY KEY (`entryId`),
  UNIQUE KEY `uniq_openid_itemkey` (`openid`, `itemKey`),
  KEY `idx_openid_grade` (`openid`, `grade`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户题库覆盖记录';
```

**没执行的后果**：`/api/wordbank/entries` 返回 5000，端上会**自动降级为本地缓存**
（用户仍能编辑、也能立刻影响出题），只是换手机 / 重装后改动会丢。所以这条不影响小程序运行，
但要「跨设备不丢」就必须执行。

## 三、接口一览

| 接口 | 说明 |
| --- | --- |
| `GET /api/wordbank/entries` | 我的全部词条改动（可按 `?grade=` 过滤） |
| `POST /api/wordbank/entries` | 保存一条改动（`action`: create / patch / disable） |
| `DELETE /api/wordbank/entries` | 删除一条改动（= 恢复内置原样 / 删掉自建词条） |

## 四、口径说明（重要）

- **内置词条是「停用」不是物理删除**：内置词库以后升级会补词，硬删会与升级冲突；
  停用可随时恢复，界面上与删除无差别。
- **改写内置词条时题目不可改**（只改释义/答案/干扰项/例句）：指纹是「学段+题型+题目」，
  题目一变就变成另一条词条，会导致原来的停用/改写记录失配。
- **改题库会改变闯关出题**：同一关的题目由「学段+关卡种子」从题池里抽，
  题池变了，重进同一关的题目可能变（已得星星不受影响）。
- 游客不能编辑题库（词条要存云端），入口与题库页都走登录门禁。
