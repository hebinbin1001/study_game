# 题库（词条编辑）· 生产库建表与部署说明

> 2026-09-18 新增功能：题库页可查看/新增/改写/停用各学段词条，且这些词条就是**闯关线的题源**。
> 用户改动存在新表 `word_entries`（云端为真源，本地另有缓存保证离线可出题）。

## 一、必须在生产库执行这两条 SQL（否则编辑不能跨设备保存）

> 2026-09-18 二次改版：新增「自建题库」（挂在学段下作为附加题源）+ 掌握状态。
> `word_entries` 增加了 `bankId` / `scopeKey` 两列 —— **这张表还没在生产库建过**，
> 所以直接用下面的完整建表语句即可（不用再单独 ALTER）。

```sql
CREATE TABLE IF NOT EXISTS `word_entries` (
  `entryId`    CHAR(36)     NOT NULL COMMENT '覆盖记录 ID',
  `openid`     VARCHAR(64)  NOT NULL COMMENT '所属用户 openid',
  `bankId`     CHAR(36)     NULL COMMENT '自建库 ID（NULL = 学段级改动）',
  `scopeKey`   VARCHAR(64)  NOT NULL DEFAULT 'base' COMMENT '归属范围：base 或 自建库 ID',
  `itemKey`    VARCHAR(191) NOT NULL COMMENT '词条指纹 grade|type|q',
  `action`     ENUM('create','patch','disable') NOT NULL COMMENT '新增/改写内置/停用内置',
  `grade`      VARCHAR(32)  NOT NULL COMMENT '学段 key',
  `type`       VARCHAR(16)  NULL COMMENT '题型码 w1/w2/c1/c2/xhy/zc/fill/trans',
  `q`          VARCHAR(255) NULL COMMENT '题目（w2/c2 为含 * 的模板）',
  `a`          VARCHAR(255) NULL COMMENT '答案',
  `hint`       VARCHAR(255) NULL COMMENT '提示 / 释义',
  `ex`         VARCHAR(512) NULL COMMENT '例句（可选）',
  `d`          VARCHAR(255) NULL COMMENT '干扰项（逗号分隔，可选）',
  `createdAt`  DATETIME     NOT NULL,
  `updatedAt`  DATETIME     NOT NULL,
  PRIMARY KEY (`entryId`),
  UNIQUE KEY `uniq_scope_itemkey` (`openid`, `scopeKey`, `itemKey`),
  KEY `idx_openid_grade` (`openid`, `grade`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户题库覆盖记录';

CREATE TABLE IF NOT EXISTS `word_banks` (
  `bankId`     CHAR(36)     NOT NULL COMMENT '自建库 ID',
  `openid`     VARCHAR(64)  NOT NULL COMMENT '所属用户 openid',
  `name`       VARCHAR(64)  NOT NULL COMMENT '库名，如「我家错词本」',
  `grade`      VARCHAR(32)  NOT NULL COMMENT '挂在哪个学段下（该学段的附加题源）',
  `enabled`    TINYINT(1)   NOT NULL DEFAULT 1 COMMENT '是否参与出题',
  `createdAt`  DATETIME     NOT NULL,
  `updatedAt`  DATETIME     NOT NULL,
  PRIMARY KEY (`bankId`),
  KEY `idx_openid_grade` (`openid`, `grade`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户自建题库';
```

**没执行的后果**：`/api/wordbank/entries` 返回 5000，端上会**自动降级为本地缓存**
（用户仍能编辑、也能立刻影响出题），只是换手机 / 重装后改动会丢。所以这条不影响小程序运行，
但要「跨设备不丢」就必须执行。

## 三、接口一览

| 接口 | 说明 |
| --- | --- |
| `GET /api/wordbank/entries` | 我的全部词条改动（可按 `?grade=` 过滤） |
| `POST /api/wordbank/entries` | 保存一条改动（`action`: create / patch / disable；带 `bankId` = 存进自建库） |
| `DELETE /api/wordbank/entries` | 删除一条改动（= 恢复内置原样 / 删掉自建词条） |
| `GET /api/wordbank/banks` | 我的自建库列表 |
| `POST /api/wordbank/banks` | 新建 / 重命名 / 启停自建库 |
| `DELETE /api/wordbank/banks` | 删除自建库（连带库内词条） |
| `GET /api/wordbank/mastery` | 我的词条掌握状态（`questionId → {w,r,m}`，题库页「薄弱/已掌握」用） |

## 五、自建库的口径（用户 2026-09-18 拍板）

- 自建库**挂在某个学段下作为附加题源**：比如给「小学3-4」建一个「我家错词本」，
  该学段闯关时和内置词库一起抽题；**不做全局 activeBank 切换**（那会让闯关线的学段参数失去意义）。
- 一个学段下可以有多个库，每个库可单独**暂停**（不参与出题，词条保留）。
- 库内词条若与内置**同题**，只显示在库里，**不会在题池里重复**（避免同一关出重复题）。
- 掌握状态直接复用错题本（`wrong_records`）：✗ = 错误次数、✓ = 复习次数、熟练度满 100 = 已掌握。

## 四、口径说明（重要）

- **内置词条是「停用」不是物理删除**：内置词库以后升级会补词，硬删会与升级冲突；
  停用可随时恢复，界面上与删除无差别。
- **改写内置词条时题目不可改**（只改释义/答案/干扰项/例句）：指纹是「学段+题型+题目」，
  题目一变就变成另一条词条，会导致原来的停用/改写记录失配。
- **改题库会改变闯关出题**：同一关的题目由「学段+关卡种子」从题池里抽，
  题池变了，重进同一关的题目可能变（已得星星不受影响）。
- 游客不能编辑题库（词条要存云端），入口与题库页都走登录门禁。
