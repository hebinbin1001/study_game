# 一笔画 35 关移植说明（2026-10-18）

> 起因：用户要求「把 demo 里面的一笔画小游戏.html 加入进来」。
> 源文件：`E:/Code/小程序/study_game/demo/一笔画小游戏.html`（2026-10-08 版，35 关手绘图形）。
> `demo/` 整目录被 gitignore，所以源文件不入库，只在本文记录来源与移植口径。

## 一、原来是什么样 / 为什么要换

| | 换之前 | 换之后 |
|---|---|---|
| 关卡 | 5 张手绘 + 29 张**公式生成**（11 张「长方形加对角线」、4 张折线…） | demo 的 35 张手绘图形（直线 → 三角形 → … → 中国结 → 终极挑战） |
| 关卡名 | 「第 N 关」 | 「第 N 关 · 五角星」+ 难度档 + 线数 |
| 难度 | 无分档，形状高度重复 | 简单 1~12 / 中等 13~24 / 困难 25~35 |
| 提示 | 无 | 每关 3 次，💡 高亮一条**走完仍能通关**的线；没起手时高亮奇点 |
| 进度 | 只有「已走线 3/8」文字 | 顶部进度条 + 文字 |
| 星级 | 按「本次连闯了几关」 | 按「本关用了几次帮助」（0 次 3 星 / 1~2 次 2 星 / 3 次以上 1 星） |

公式生成的问题很实际：34 关里有 11 关长得几乎一样，玩家第 8 关就腻了；
而且难度和形状复杂度无关（第 13 关的长方形比第 5 关的五角星还简单）。

## 二、怎么移植的

- **不用 Canvas**。demo 用 `canvas.getContext('2d')` + `requestAnimationFrame` 风格重绘，
  小程序里 Canvas 的触摸坐标、DPR 缩放、层级都要另写一套，而且**没法在 Node 下单测**。
  沿用本项目已有做法：绝对定位的 `view` 当线（`left/top/width + rotate`）、圆点当节点，
  几何全部由 `game/one-stroke.js` 的 `geometry()` 算出。
- **坐标口径**：demo 是 0~1 归一化，改成 0~100 相对坐标，与 `klotski-levels` / `math24-levels` 一致。
- 关卡数据落在 `miniprogram/game/one-stroke-levels.js`（纯数据）；规则留在 `game/one-stroke.js`。

## 三、提示怎么做才不坑人

demo 的提示是「从当前点还能走的边里随机挑一条」。问题：随手挑一条可能把人带进死路，
提示反而害人。这里改成**按欧拉路径判定筛**：

1. 假设走这一步，得到剩余图；
2. 剩余图必须连通，且奇点数为 0（回路，任意点都能收尾）或 2（且新位置必须是奇点之一）；
3. 只高亮满足条件的边；一条都不满足（说明已经走错了）→ 仍给一条能走的，但标 `safe=false`，
   页面提示「建议先撤销」。

单测 `tests/unit/one-stroke.test.js` 里对 35 关逐一验证：**从起点开始一路照着提示走，
必定能画完**，且每一步都 `safe=true`。
