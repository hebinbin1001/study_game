# 玩法界面优化清单（2026-10-17 审计）

> 范围：16 个玩法页的**界面与交互**（不是数值）。数值口径的改动见 `游戏玩法优化方案.md`。
> 每条都标了证据（文件 / 截图现象）、建议、代价。按「影响玩家感受」排序。

## 1. 结算界面有两套实现（最该统一）

**证据**：`settle-pop` 组件用在 10 个页面（match / word-build / idiom-build / math-sprint /
math-balance / memory-grid / one-stroke / sudoku / klotski / quiz）；另外 5 个页面自己画遮罩
（link / snake / bounce / math24 / g2048 的 `over-mask` / `o-mask`）。

**现象**：同样打完一局，结算的星星大小、按钮位置、「再来一次 / 下一关」的文案都不一样。
两套代码还各自维护一份"下一步"逻辑，改一处容易漏另一处。

**建议**：统一到 `settle-pop`，并给它加两个能力：
- `hint` 插槽：显示「再答对 1 题就是 3 星」这类差一点提示（见第 6 条）；
- `onNext` 为空时自动只显示「重玩 / 返回」。

代价：1 天；要把 5 个自绘页接进组件，注意它们各自的"下一关"逻辑。

## 2. 除了字母射击，其他玩法都不能暂停

**证据**：只有 `pages/game` 的 HUD 有 ⏸ 暂停与 🔊 音量；其余 15 个页面中途被叫走只能退出，
退出即丢当局进度。

**建议**：在统一的 HUD 右侧加「⏸」按钮，点开弹窗：继续 / 重开本局 / 退出 / 音量开关。
字母射击那套弹窗已有，可直接抽成公共组件。

代价：1.5 天（16 个页面各接一行 + 组件）。

## 3. 4×4 棋盘类页面中部留白约占 1/3

**证据**：消消乐、连连看、24 点的截图里，棋盘/卡片与底部提示之间有大块空白
（消消乐棋盘结束到 tip 约 180px）。原因是棋盘受 4 列宽度限制，纵向撑不满。

**建议**（三选一或组合）：
- 棋盘容器 `flex:1` + 内部等比放大（在宽度允许的范围内取更大的 `max-width`）；
- 把「剩余 X 对 / 已用 Y 步」做成棋盘下方的进度条，填掉空白；
- 底部操作区上移贴住棋盘，空白留在最底部（视觉上比中间断裂好）。

代价：0.5~1 天，纯样式。

## 4. 进度指示各写各的

**证据**：
- 字母射击：`第 3/10 题`；抢答：`3/10`；拼词/成语：`第 3/8 题`；天平：`第 3/10 题`；
- 消消乐：`剩 16 卡`；连连看：`剩 16 牌`；贪吃蛇：目标词卡里的 `第 x/y 词`；记忆矩阵：`第 N 关`。

同一个 HUD 位置，有的给"第几题"，有的给"剩多少"，玩家无法估算还剩多久。

**建议**：HUD 固定三格——`进度 n/N`、`错误/命`、`分数`；"剩多少张牌"这类信息下沉到棋盘角标。

代价：1 天（16 个页面统一，需要逐页对齐数据）。

## 5. 答错反馈强度不一致

**证据**：字母射击答错有「Boss 反击动画 + 扣盾 + 连击清零」；消消乐只有卡片抖动；
拼词只是槽位闪红；连连看是红色描边。

**建议**：抽出统一的三段反馈：
1. 画面：短促抖动（已有，统一时长 0.3s）；
2. 数值：命/盾 -1 的浮动字（`-1 ❤`）；
3. 提示：正确词义/答案的短暂显示（学习型产品，答错正是教学点）。

代价：1 天；提示文案要接题库的 `hint` 字段。

## 6. 结算页没有「差一点」提示（与刚改的星级口径直接相关）

**证据**：三档阈值 90/70/60，差 1 题就从 3 星掉 2 星，但结算只显示结果，不告诉玩家差多少。

**建议**：结算页加一行动态文案：
- 3 星差 1 题 → 「再答对 1 题就是 3 星 ⭐⭐⭐」
- 2 星差 2 题 → 「再答对 2 题升 2 星」
- 失败 → 「答对 6 题就能通关，你答对了 5 题」

代价：0.5 天，纯前端；**零风险，建议先做**。

## 7. 附：几个零散但真实的小问题

| 现象 | 位置 | 建议 |
|---|---|---|
| 抢答页右上角战士徽章与「挑战第 X 关」标签挤在同一行 | `pages/quiz` | 徽章下移 8rpx 或标签左对齐 |
| 华容道选关页 8 个格子只解锁 1 个，其余全是 🔒 + 数字，信息密度低 | `pages/klotski` | 锁定格只显示锁 + 关卡号，不显示难度副标题 |
| 数字智力页面（天平/记忆/一笔画）背景色与主的天空系差得远 | 各页 wxss | 收口批次统一或保留主题色（需拍板） |
| 拼词/成语页中部 slots 悬浮在页面中间，上下都空 | `word-build` / `idiom-build` | slots 贴紧题面卡，底部字母面板贴底 |

### 未做（原因）

- **② 统一暂停/音量**：要给 16 个页面各接一个组件，改动面最大；建议单独一批做，先抽 `game-pause` 组件再逐页接。
- **③ 4×4 棋盘留白**：棋盘受 4 列宽度限制，纵向空白是数学必然（4 行 × 正方形 = 高度上限），
  压不掉；能做的只有「空白里放信息」，属设计取舍，等确认要不要加进度条/计时再动。
- **⑤ 错误反馈三段式**：涉及 16 个页面的答题流程与题库 `hint` 字段，风险高于收益，建议排在暂停之后。
