## 二、在我们小程序里怎么放（定位）

按此前拍板：**固定关卡类（A 类）不进挑战主线，保持独立入口**。华容道属于纯智力数字游戏，因此：

- 玩法 tab 新增一款「🧩 华容道」（已解锁玩法 13 → **14** 款）；
- 页面内自带**关卡选择**（4 档 30 关，锁/星与他人页面一致：上一关 ≥1 星解锁下一关）；
- 不进挑战主线，也不占用「继续挑战」卡片；
- 与数独 / 2048 / 24 点 / 一笔画 同一套**存档与星级**（`storage.saveStars('klotski', level, stars)`，键形如 `klotski@<level>`）。

## 三、移植方案（技术）

### 3.1 引擎：`miniprogram/game/klotski.js`（纯逻辑，可单测）

从参考实现的 `<script id="core">` 移植并改成我们项目风格（CommonJS、纯函数、无 wx 依赖）：

| 函数 | 作用 |
|---|---|
| `parseGrid(rows)` | 关卡字符串网格 → 棋子数组（含 名称/尺寸/位置） |
| `buildOcc(pieces)` | 棋子占位表（含出口判定用） |
| `maxSlide(occ, pieces, i, dx, dy)` | 某子在某方向**最多能滑几格**（0 = 不动） |
| `applyMove(pieces, i, dx, dy, dist)` | 执行一次滑动（返回新棋子数组，不改原数组） |
| `isWin(pieces)` | 曹操是否到达底边中间出口 |
| `packKey / unpackKey` | 局面编码（BFS 去重 + 存档用） |
| `solve(pieces, opts)` | BFS 求最优解（`opts.full=true` 返回完整路径用于「演示」，否则只算首步用于「提示」） |
| `starsFor(minMoves, moves)` | ≤1.15× → 3★、≤1.5× → 2★、否则 1★ |

### 3.2 求解性能：先测，再决定「实时算」还是「预制解」

参考实现是在浏览器里实时 BFS 的。小程序端我们要先量：

1. 在 Node 侧用我们的引擎跑一遍 30 关的 `solve()`，记录耗时（参考项目已验证状态空间 53,954，Node 上应在百毫秒级）；
2. **不论快慢，关卡数据里都随关带一条最优解路径**（生成时算好）——演示直接放，不依赖端上算力；
3. 「提示」策略：玩家仍走在最优解的轨道上 → 直接用预制解的下一步（瞬时）；已经走偏 → 才现算 BFS（并加 300ms 超时保护，超时就提示「按 R 重来可看完整演示」）。

### 3.3 交互：拖拽为主 + 点击兜底

- **拖拽（主）**：`touchstart/touchmove/touchend` 判定主轴方向与位移量 → 滑到该方向尽头（受阻挡为止），**一次拖拽记 1 步**（与参考口径一致，公平性靠它）；
- **点击（兜底）**：点棋子选中 → 点方向键或点目标格滑 1 格（每次记 1 步），方便单手/精细操作；
- 棋盘容器需 `catchtouchmove` 阻止页面滚动（否则拖动会把页面带着滚）。

### 3.4 关卡数据：`miniprogram/data/klotski-levels.js`（构建产物，勿手改）

新增 `e2e/gen-klotski-levels.js`（Node），从参考项目 `tools/levels.json` 读取 30 关，**生成时逐关校验**：

1. 棋子组合合法（恰好 1 曹 + 4 竖将 + 1 横将 + 4 兵 + 2 空）；
2. 用我们的引擎 BFS 求最少步数，**必须等于关卡标注的 `minMoves`**（不一致就报错退出）；
3. 解路径可回放：逐步执行后确实到达出口；
4. 关卡唯一（局面去重）、难度单调递增；
5. 顺带产出每关最优解路径（`solution`）与关卡元信息（名称 / 档位 / 是否经典）。

输出格式与现有 `data/math24-levels.js`、`data/sudoku-levels.js` 对齐，便于统一测试与展示。

### 4.2 视觉（我们的语言，不用参考实现的皮肤）

- 棋盘：深色渐变底板 + 圆角格线（与「记忆矩阵」同一套深蓝发光语言，但走**暖色棋子**以免和数字游戏撞脸）；
- 棋子配色（主色取自我们现有色板）：
  - 曹操 2×2：**主色红金**（`#ff5d8f`→`#ffb703` 渐变 + 金边），最大最显眼；
  - 五将（关/张/赵/马/黄）：蓝紫系（`#4cc9f0` / `#b388ff`），可按竖/横区分深浅；
  - 兵 1×1：绿色（`#7bd389`）；
  - 出口：金色虚线门 + 「出」字水印，曹操贴上去时有呼吸高亮；
- 硬阴影 + 圆角 + 大字号，与首页/结算页一致；拖动时棋子抬起（`translateY + 阴影变大`），落位有 120ms 过渡；
- 棋子命名：**保留经典三国名（曹操/关羽/张飞/赵云/马忠/黄忠/兵）**——玩家认知成本最低，也自带情怀。若你想统一到我们的世界观，可换成「大魔王 / 怪兽小兵 / 战士」一套皮（待确认）。

### 4.3 音效与动效（二期）

- 滑动「嗒」、通关「叮咚」、卡住提示音；演示时逐格动画播放。一期先做静音可用的版本。
