# 导航入口梳理 · 三层模型（2026-10-18）

> 用户反馈：从主页 Boss 入口进去，关卡页里的「自由练习」和「玩法」tab 内容一致，入口混乱。
> 本文先给现状地图与证据，再给两个可选方案。**未改代码**。

## 一、现状：三个门，通向同一批内容

```
首页
 ├─ ⚔️ 出战 ───────────────→ 对局（主线当前关）
 ├─ Boss 信息条/换关卡 ────→ 关卡页 · 主线视图（30 关）
 └─ 🔥 热门玩法卡 ─────────→ /pages/level/level?mode=xxx
                                   ↓（mode 非空 → 自动切到「自由练」视图）
                             关卡页 · 自由练（玩法线 30 关 + 题型 chips）

玩法 tab（playlist）
 ├─ 年级 chips + 分类 chips + 玩法网格
 └─ 点任意卡片 ────────────→ /pages/level/level?mode=xxx
                                   ↓
                             关卡页 · 自由练（和上面完全同一份内容）
```

**证据**
- `utils/game-catalog.js`：每款玩法的 `url` 都是 `/pages/level/level?mode=...`；
- `playlist.js` 的 `onGameTap` 直接 `navigateTo(g.url)`；
- `level.js`：`?mode=` → 设 `currentType` → `refresh` 里 `viewTab = typeKey === 'all' ? 'main' : 'free'`，
  即“带玩法参数进来”必然落在自由练视图。

**由此产生的三个具体问题**
1. 玩法页点卡片不是“开始玩”，而是“再进一层列表”，多一次跳转才到对局；
2. 关卡页的「自由练」与玩法页展示同一批玩法（一个用 chips、一个用卡片），命名也不同（自由练 / 闯关线），同一个东西两套叫法；
3. Boss 入口进的是主线，但同一页上就摆着「自由练」分段，看起来像是“Boss 也能自由练”。

## 二、方案 A：三层模型（推荐）

一句话：**每个入口只回答一个问题**。

| 页面 | 回答的问题 | 内容 |
|---|---|---|
| 首页 | 我现在该干什么？ | 出战（继续主线）/ Boss / 今日任务 / 热门玩法 |
| 玩法 tab | 我想玩什么？ | 全部玩法目录；点卡片**直接开局**，卡片角上「关卡 ›」才进关卡列表 |
| 关卡页 | 我在主线的哪一关？ | 只保留主线 30 关 + 宝箱 + 继续当前关；**删掉自由练分段** |

改动清单：

1. **关卡页去掉「自由练」**
   - 删 `view-seg` 的「🎲 自由练」分段、`freeGroups` chips、`_buildLineRows` 分支；
   - 底部加一行：「想随便玩？去玩法挑一个 ›」→ `wx.switchTab('/pages/playlist/playlist')`。
2. **玩法页卡片直接开局**
   - `onGameTap` 改为：读当前年级 → `storage.findContinueLevel(grade, lineKey, 30)` → `challenge.lineUrl(grade, mode, level)` 直达对局；
   - 卡片右下加一个「关卡 ›」小按钮（`catchtap`），进 `/pages/level/level?mode=xxx` 看 30 关列表。
3. **首页热门卡直接开局**
   - 目前热门卡 url 也是 `level?mode=`，改为用同样的“继续该玩法线”逻辑直开；
   - 卡片上保留“第 N 关”字样，让人知道会从哪一关开始。
4. **Boss 入口语义固定**
   - Boss 条只进主线（现状已经是），不要因为它所在页面有自由练而产生歧义；配合第 1 条自动消失。

代价：关卡页删一段（约 40 行 wxml + 60 行 js）、玩法页跳转改造（约 30 行）。风险：中——关卡页是高频页，要补一条结构护栏（“关卡页不得再出现玩法线视图”）。

## 三、方案 B：最小去重（只删重复，不改跳转）

只做 A 的第 1 条：**关卡页删掉自由练，改为一行跳玩法 tab**。
玩法页卡片仍进关卡页看关卡列表。

- 优点：改动最小（只动关卡页），立刻消除“两处自由练”；
- 缺点：玩法页点卡片仍要再跳一层，多一次点击；且关卡页 `?mode=` 入口（首页热门卡）会落空，需要一并改成跳玩法 tab，否则热门卡点了没反应。

## 四、两方案对比

| | A 三层模型 | B 最小去重 |
|---|---|---|
| 消除重复 | ✅ 彻底 | ✅ 自由练只剩玩法页 |
| 玩法页点卡片 | 直接开局（少一跳） | 仍进关卡列表（多一跳） |
| 改动面 | 关卡页 + 玩法页 + 首页热门卡 | 仅关卡页 + 首页热门卡改跳转 |
| 风险 | 中（动了关卡页视图切换） | 低 |
| 后续扩展 | 新玩法只登记到玩法页，天然不进主线 | 仍需维护两处视图 |

## 五、建议

先做 **A**，但分两步落地，方便回滚：

1. 第一步（低风险）：关卡页删自由练 → 跳玩法 tab；首页热门卡改跳玩法 tab。这一步做完，重复感就没了；
2. 第二步（体验优化）：玩法页“点卡直接开局 + 角标进关卡列表”，首页热门卡也跟着直达对局。

如果只想先解决“混乱”，做第一步即可；第二步是省一次点击。
