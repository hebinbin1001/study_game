# 全局年级设置方案（2026-10-18）

> 用户反馈：关卡页的年级选项（14 个 tab）太长、不好用；希望「在主页或我的选一次年级，
> 其他地方不再显示，题库直接用这个年级」。
> 本文先给现状与方案，**未改代码**。

## 一、现状：年级在 4 个地方各选一次

| 页面 | 形态 | 是否写 `ww_last_grade` |
|---|---|---|
| 关卡页 `pages/level` | 顶部 14 个学段 tab（可横向滚动） | ✅ 写（`pickGrade`） |
| 玩法页 `pages/playlist` | 顶部年级 chips + 已解锁计数 | ✅ 写（`pickGrade`） |
| 词库页 `pages/bank` | 顶部年级 tab | ❌ 只在本页生效，不写全局 |
| 每日挑战 / PK | 读 `storage.getLastGrade()`，页面内不能改 | 只读 |

**问题**
1. 同一个「年级」在三个页面各有一套选择器，长度都超过一屏宽度（14 项）；
2. 词库页选的年级不写全局，和关卡页会不一致（同一用户两页看到的年级不同）；
3. 用户每次想换难度，都要在长 tab 里横向找。

年级的作用面比想象大：主线 30 关、玩法线 30 关、词库、每日挑战、好友 PK 都按它取题。
所以它本质上是**一个学习设置**，不是页面级筛选器。

## 二、目标模型

> **年级 = 全局学习设置，只有一处能改，其余页面只读复用。**

- 单一存储：沿用现有 `ww_last_grade`（已存在，无需迁移）；
- 单一设置入口：**我的 → 学习 → 当前年级**（和「教材版本」并排，两个都是学习设置）；
- 首次使用：没有年级时（新用户/清缓存），在进入关卡页或玩法页前弹一次选择器，选完才能继续；
- 其余页面：只显示一行只读文字（如「三年级」），不再出现长 tab；
- 每日挑战 / PK：自动跟随，无需再传参。

## 三、具体改动

### 3.1 新增组件 `components/grade-picker`

半屏弹层，14 项两列网格（每项：学段名 + 段位色块），底部「确定」。

- properties：`visible`、`value`（当前 gradeKey）
- events：`pick`（`detail.key`）、`close`
- 复用现有 `constants.GRADES`，不新造数据

### 3.2 我的页（唯一设置入口）

在「学习」分组里，「教材版本」上方加一行：

```
🏫 当前年级 · 三年级   ›
```

点击打开 `grade-picker`；选完 `storage.setLastGrade(key)`，Toast「已切换到三年级」。
和「教材版本」放在一起，语义一致：这两个都决定“出什么题”。

### 3.3 关卡页

- 删掉顶部 14 个学段 tab；
- 换成一行只读：「三年级 · 主线 30 关」（点击可打开同一个 picker，方便但非必须）；
- `currentGradeIndex` 改为由 `storage.getLastGrade()` 推导；`pickGrade` 方法删除；
- 没设置年级时：进页面先弹 picker，选完再渲染关卡。

### 3.4 玩法页

- 删掉年级 chips 与 `unlockedCount/totalCount` 那一行（计数并入页脚或分类行）；
- 只读显示当前年级；
- `pickGrade` 删除。

### 3.5 词库页

- 同样删掉年级 tab，改为只读；顺带修掉「这里选的年级不写全局」的不一致。

### 3.6 切换年级的影响（要在 UI 上说明）

- 主线星级按 `<学段>@challenge@<关卡>` 存：切年级 = 换一整套 30 关，**各自独立、互不覆盖**；
- 玩法线同理（`<学段>@mode_x@<关卡>`）；
- 段位/星星是全局的，不随年级变；
- 切换后如果该年级一关没打过，会从第 1 关开始（前 3 关默认解锁）。

建议在 picker 里加一行小字：「切换年级会显示该年级的关卡与题目，已有进度都会保留。」

## 四、代价与风险

| 项 | 评估 |
|---|---|
| 组件 + 4 个页面改造 | 约 1.5~2 天 |
| 风险 1：发现性 | 年级从“页面内随手可切”变成“我的里设置”，需要在首次使用和只读标签上给出足够暗示（标签可点开 picker） |
| 风险 2：误切换 | 切年级会换一整套进度，picker 里要写明；不做二次确认（儿童产品不宜多一步） |
| 风险 3：游客 | 年级是本地偏好，游客也能用；登录后是否随账号同步，本次不做（现状也不云端存） |

## 五、验收

1. 新用户第一次进关卡页 → 弹年级选择 → 选完进入对应年级第 1 关；
2. 我的 → 当前年级 → 切到四年级 → 关卡页/玩法页/词库/每日挑战全部变成四年级；
3. 关卡页、玩法页、词库页不再出现 14 项横向 tab；
4. 切回三年级，原进度与星级仍在；
5. 护栏：`level / playlist / bank` 不得再调用 `storage.setLastGrade`（只有我的页能改）。
