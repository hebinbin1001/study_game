## 一、题库与教材同步（核心）

### 已修 ①：低年级通用词表混入高年级词（越级）

用「教材词表源里该词最早出现的年级」当基准做反查，查出 21 条越级：

| 年级 | 越级词 | 教材里实际年级 |
|---|---|---|
| 一年级 | grape / peach / watermelon / lemon / meat / tea / candy | 三年级 |
| 一年级 | soup | 四年级 |
| 二年级 | doctor / nurse | 五年级 |
| 二年级 | street | 四年级 |
| 二年级 | river / lake / mountain / city | 六年级 |
| 三年级 | important / remember / always / never / usually / quietly | 五年级 |

处理：从低年级删除（这些词在对应高年级**都已经存在**，不会丢内容）。
删后为补足题量，补进真正属于低年级的词：一年级 hello / hi / bye / goodbye（外研版第一课就有了，原词表从 pen 开始，漏了问候语）；二年级 uncle / aunt / cousin / baby（"家里的人"主题原词表没有词）。

### 已修 ②：教材版本覆盖被误读

原「我的 → 教材版本」只列版本书名，家长无法判断"我这个年级到底同步没同步"。实际覆盖：

| 年级 | 通用 | 人教版 PEP | 外研版 |
|---|---|---|---|
| 幼儿园 | 100 | — | — |
| 一年级 / 二年级 | 54 / 59 | **0（PEP 是三年级起点）** | 98 / 91 |
| 三年级 | 94 | 119 | 40 |
| 四年级 | 99 | 96 | 40 |
| 五年级 | 101 | 93 | 39 |
| 六年级 | 91 | 97 | 40 |
| 初一 ~ 高三 / 大学 | 全部 | **0（暂无分版本）** | **0** |

处理：
- 选择器改为「人教版 PEP · 本年级 119 词 / 本年级暂无」，选到"暂无"时提示"本年级词表尚未补齐，先用通用词表出题"；
- 「我的」菜单里当前版本若在本年级无词条，直接标注「（本年级暂无）」，不等点进去才发现。

### 说明（不改，属产品现状）

- **部编版 bjb 没有任何词条**：语文题（汉字/成语/歇后语）本身不分版本，选它等价于通用。属于"选项名存实亡"，**2026-10-18 已删除该选项**（见第七节）；
- **中学/大学没有分版本词表**：中考/高考词汇统一，`general-words.js` 已按此口径写；**2026-10-18 拍板不细分**，初高中不再给版本切换入口（见第七节）。

## 二、音标（教材 DJ 写法）

**问题**：词库音标直接从 `ipa-dict` 抄，而该词典把重音符标在**重读元音前**（`cat /kˈæt/`、`blue /blˈuː/`、`brother /bɹˈʌðɐ/`），教材是标在**音节起首前**（`/kæt/`、`/bluː/`、`/ˈbrʌðə/`），单音节词教材干脆不标。**1645 条**受影响 —— 学生拿课本对照会看到重音符整体错位一格。

**修复**：
- 新增 `tools/dict/ipa-normalize.js`：符号归一（ɹ→r、ɫ→l、ɐ→ə、ɝ→ɜː）+ 重音归一（单音节去重音；多音节按「最长合法音节首」把 ˈ 挪到 onset 前，`important ɪmpˈɔːtənt → ɪmˈpɔːtənt`、`music mˈjuːzɪk → ˈmjuːzɪk`）；
- `add-ipa.js` 入库时复用同一套规则（以后新补的词不会再写错）；
- `tools/dict/fix-ipa-stress.js` 修存量，**幂等**（跑第二遍改动 0 条）。

结果：待规整 0 条；13 条缺音标全是多词短语/变形（`hot dog`、`is doing`），词典查不到，界面会自动隐藏该行。

## 三、回归中发现的两处测试基建问题

## 七、教材版本口径（2026-10-18 落地）

### 1. 删除「部编版 bjb」

| 改动点 | 文件 |
|---|---|
| 前端版本清单删 `bjb`，并说明"只做英语教材版本" | `miniprogram/utils/constants.js` |
| 服务端白名单删 `bjb`（前端能选/服务端拒收的口子一并关上） | `server/book-keys.js` |
| 表注释、接口注释同步 | `server/ensure-tables.js`、`server/routes/user.js` |
| 一致性测试改成"通用 + pep + wys"，并断言 `bjb` 已非法 | `tests/unit/book-keys-parity.test.js` |

兼容性：本地存过 `bjb` 的老用户，`storage.setBook()` 写前置校验 + `constants.isValidBook()` 会把它落回「通用」；题库页教材 chip 由 `BOOKS` 生成，自动不再出现该档。

### 2. 初高中不区分教材版本

`constants.isBookSelectable(gradeKey)`：`kg~g6` 为 true，`g7~g12`、`college` 为 false。

- 「我的 → 教材版本」：初高中时菜单直接显示「教材版本 · 初高中统一（不区分）」，点进去弹一段口径说明，**不给切换**（给一个"选了也不生效"的选项比不给更糟）；
- 题库页：初高中隐藏整段教材筛选，只显示「当前教材：初高中统一（不分版本）」，避免「人教版 0 / 外研版 0」的空 chip；
- 小学/学前：维持原行为（人教版 PEP / 外研版 + 通用兜底，选到"本年级暂无"会说明回退原因）。

### 3. 将来要细分时的推荐做法（按成本从低到高）

1. **先补词表，再放开关**。顺序反了会出现"切了版本但题没变"的投诉，比没有这个功能更伤。
2. 词表来源与现有小学一致：`tools/dict/book-words-pep.js` / `book-words-wys.js` 追加初中（7~9）与高中（10~12）册次，字段沿用 `book: 'pep' | 'wys'`；
3. 初高中以**册次/模块**为单位标注（PEP 高中必修 1~3、选择性必修 1~4；外研版必修 1~3、选择性必修 1~4），不要按"年级"硬对齐——各地进度不同，按册次更稳；
4. 入完跑 `node tools/dict/audit-dict.js --strict`，覆盖率达到出题下限（`MIN_BOOK_ITEMS`）后再把 `isBookSelectable` 放开到对应年级；
5. 高考词汇统一这条口径保留：即使细分，也保留「通用（中高考词汇）」作为第一项，避免用户没选就被塞进某版本。
