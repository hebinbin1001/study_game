### 不上排行榜的（18 人，没设昵称）

其中 **只有 2 个是自动化测试账号**（`test_openid_...`），另 **16 个是真实微信用户**：
他们用微信登录过、有人还玩了几十局，只是**没走完「设昵称」这一步**，所以一直不上榜。

| 类型 | 数量 | 说明 |
| --- | --- | --- |
| 测试账号（`test_openid_*`） | 2 | E2E 自动化跑出来的，可放心删 |
| 真实用户 · 没设昵称 · 有成绩 | 6 | 最多的一位 29 局 |
| 真实用户 · 没设昵称 · 无成绩 | 10 | 登录过，一局没玩 |

⚠️ **删除后：这些人再打开小程序会用同一个 openid 重新建号，历史成绩清零**（他们本来也不上榜）。

## 二、先决定删哪一档

- **方案 A（保守）**：只删 2 个测试账号。
- **方案 B（彻底）**：删掉全部 18 个没昵称的用户 —— 就是「排行榜以外的都清掉」。

下面 SQL 按 **方案 B** 写。想走方案 A，把每处 `(nickname IS NULL OR TRIM(nickname) = '')`
换成 `openid LIKE 'test\_openid\_%'` 即可。

## 三、执行步骤

### 第 1 步：先看一眼要删谁（只查不删）

```sql
SELECT id, openid, nickname, createdAt
FROM users
WHERE (nickname IS NULL OR TRIM(nickname) = '')
ORDER BY createdAt;
```

确认结果里**没有**「追梦007 / 超级无敌雷霆玩具 / 皮皮 / 超级无敌宇宙第一帅」这 4 个。

### 第 2 步：备份（出问题能还原，几秒钟的事，别跳过）

```sql
CREATE TABLE IF NOT EXISTS backup_users_20260929 AS
SELECT * FROM users WHERE (nickname IS NULL OR TRIM(nickname) = '');

CREATE TABLE IF NOT EXISTS backup_scores_20260929 AS
SELECT s.* FROM scores s JOIN users u ON u.id = s.user_id
WHERE (u.nickname IS NULL OR TRIM(u.nickname) = '');

CREATE TABLE IF NOT EXISTS backup_rank_records_20260929 AS
SELECT r.* FROM rank_records r JOIN users u ON u.openid = r.openid
WHERE (u.nickname IS NULL OR TRIM(u.nickname) = '');
```

### 第 3 步：删除（事务包裹，出错整体回滚）

```sql

  WHERE (u.nickname IS NULL OR TRIM(u.nickname) = '');

DELETE r FROM rank_records r JOIN users u ON u.openid = r.openid
  WHERE (u.nickname IS NULL OR TRIM(u.nickname) = '');

  WHERE (u.nickname IS NULL OR TRIM(u.nickname) = '');

  WHERE (u.nickname IS NULL OR TRIM(u.nickname) = '');

  WHERE (u.nickname IS NULL OR TRIM(u.nickname) = '');

  WHERE (u.nickname IS NULL OR TRIM(u.nickname) = '');

  WHERE (u.nickname IS NULL OR TRIM(u.nickname) = '');

  WHERE (u.nickname IS NULL OR TRIM(u.nickname) = '');
```

想连自建关卡一起清，先跑这句看有多少：

```sql
SELECT COUNT(*) AS 无昵称用户的自建关卡数
FROM custom_levels cl JOIN users u ON u.openid = cl.authorOpenid

```

### 第 4 步：校验

```sql
-- 应该只剩 4 个用户，且每个都有昵称
SELECT id, nickname, createdAt FROM users ORDER BY createdAt;

-- 应该没有空昵称残留
SELECT COUNT(*) AS 空昵称残留 FROM users WHERE (nickname IS NULL OR TRIM(nickname) = '');

-- 成绩应只剩这 4 个人的
SELECT u.nickname, COUNT(*) AS 局数 FROM scores s JOIN users u ON u.id = s.user_id
GROUP BY u.nickname;
```
